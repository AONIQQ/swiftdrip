# SwiftDrip Comprehensive Wellness - Website

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **CMS**: Sanity (headless)
- **Fonts**: Playfair Display (headings), DM Sans (body)
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Color Scheme
- Primary Blue: `#0033A0`
- Dark Navy: `#111827`
- Deep Blue: `#001F5C`
- Light Blue Mist: `#F0F4FA`
- Blue Light: `#E8ECF4`
- White: `#ffffff`

## Project Structure
```
src/
  app/              # Next.js App Router pages
    (site)/         # Site pages group
    studio/         # Sanity Studio
  components/       # Reusable UI components
  lib/              # Constants, utilities
  sanity/           # Sanity client, schemas, config
public/
  logo.jpg          # SwiftDrip logo
```

## Design Principles
- Expert medspa-level design: clean, premium, aesthetic
- Follow the Frontend Design Skill guidelines - visually striking, not cookie-cutter
- Blue color scheme consistent with existing SwiftDrip branding
- Serif headings (Playfair Display) for elegance, sans-serif body (DM Sans) for readability
- Subtle animations with framer-motion (scroll-triggered reveals)
- Mobile-first responsive design
